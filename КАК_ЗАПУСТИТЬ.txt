Учёт пилатеса — отдельная версия для iPhone

1. Выложите все файлы из этой папки на любой статический хостинг (например GitHub Pages, Netlify Drop, Cloudflare Pages). Личных данных в файлах нет.
2. Откройте адрес в Safari на iPhone → «Поделиться» → «На экран „Домой“».
3. Вносите данные только в приложении с экрана «Домой»: у него своё хранилище, отдельное от Safari.
4. Раз в 1–2 недели: вкладка «Копия» → «Выгрузить в Excel». Файл можно загрузить обратно кнопкой «Загрузить».
5. После первого открытия приложение работает без интернета.
6. Если обновите файлы на хостинге, поменяйте версию в sw.js (pilates-v2 → pilates-v3).
